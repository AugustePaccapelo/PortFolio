Contexte

Morse Learner est un projet réalisé en solo durant ma première année à ISART Digital.
Le sujet était de créer un jeu qui soit à la fois un One Button Game et un Serious Game.

J'ai choisi de créer un jeu mobile autour de l'apprentissage du morse, en utilisant uniquement la durée d'appui du joueur pour différencier les entrées.

Pitch

Le joueur doit reproduire des lettres en code morse.
Un appui court crée un point, tandis qu'un appui long crée un tiret.

L'objectif est de mémoriser progressivement l'alphabet morse grâce à un système de feedback visuel, d'animations et de progression par lettres.

Mon travail

La vérification du morse

J'ai créé un système qui convertit les lettres en code morse, puis compare les entrées du joueur avec la lettre demandée.

À chaque point ou tiret ajouté, le jeu vérifie si la séquence est encore correcte. Si le joueur se trompe, la combinaison est réinitialisée et un feedback d'erreur est lancé.

La progression d'apprentissage

J'ai mis en place un mode d'apprentissage qui introduit les lettres progressivement.
Le joueur commence avec peu de lettres, puis en débloque de nouvelles après plusieurs bonnes réponses d'affilée.

Le feedback visuel

J'ai travaillé sur les animations et les retours visuels des symboles.
Les points et les tirets apparaissent avec une animation, changent d'état lorsqu'ils sont corrects, et se cassent lorsque le joueur fait une erreur.

Ces feedbacks permettent au joueur de comprendre rapidement s'il est sur la bonne séquence ou non.
