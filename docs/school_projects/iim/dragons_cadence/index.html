3 Game Programmers
3 Game Designers

Pitch

Le joueur doit apporter les notes de musique dans la gueule du ou des dragons. Pour cela, il doit placer des instruments de musique pour guider les notes.

Walkthrough

Mon travail

Placement des instruments

Le joueur a un nombre limité de chaque instrument, il peut les placer où il le souhaite tant que ce n'est pas sur un obstacle ou un autre instrument. Chaque instrument peut également être tourné, librement ou non.

Les succès

Je me suis occupé de la connexion aux services de Google Play. On s'en est servi pour mettre des succès dans le jeu.

Les cadenas

Il y a certaines zones du niveau bloquées par une chaîne avec un cadenas. Dès qu'une note touche une clé de Fa ou de Sol, le cadenas et sa chaîne correspondante disparaissent pour rendre accessible la zone.

Animations du rythme des instruments

Suite à des problèmes durant le développement, le jeu n'a pas autant de juiciness que l'on voulait.

Malgré tout, j'ai pu utiliser mon package TweenCore pour rapidement inclure de simples animations synchronisées sur tous les instruments.

Le tambour rythmé

Le premier instrument que j'ai réalisé est celui ci-contre. La note rebondit dessus seulement sur un certain tempo. Le joueur peut choisir ce tempo avec un bouton lorsque l'instrument est sélectionné.

La trompette

J'ai également réalisé la trompette. Comme le tambour, elle n'est active que pendant un certain temps. Son effet est similaire aux flux de gravité dans Portal 2.

Le Cor

J'ai participé à l'intégration du cor. La mécanique était faite, cependant l'instrument n'était pas utilisable en jeu dans son état.

Aides pour le LD

Pour faciliter la création de niveaux, les éléments qui peuvent avoir des visuels alternatifs avaient une simple variable exposée qui changeait automatiquement les visuels et leurs comportements.

Cela permettait aux Game Designers d'utiliser le même prefab pour chacun des éléments, et de les modifier au besoin facilement.

Niveaux avec plusieurs types de notes

Certains niveaux ont 2 bardes, 2 notes et 2 dragons différents. Ici on peut les différencier facilement avec les couleurs.

Avec le système permettant aux prefabs de changer automatiquement de visuel, ça a été très simple d'implémenter ce genre de niveaux.

Les instruments délabrés

Chaque instrument a une version délabrée, qui peut être utilisée dans le level design de n'importe quel niveau.

Ils fonctionnent de la même manière que les instruments classiques, sauf que le joueur ne peut pas les modifier ou déplacer.
